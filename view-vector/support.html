Common questions

My AI file will not open

ViewVector opens PDF-compatible Illustrator files (AI 9 and newer). Older native AI files, and files saved without the PDF compatibility option, cannot be read. Open the file in Illustrator and re-save it with Create PDF Compatible File enabled, then try again.

My DXF file is empty, or looks simplified

ViewVector renders 2D drawings. DXF files that contain only 3D entities (SOLID, 3DFACE, MESH and similar) have nothing to display. Advanced styles, hatches and custom linetypes may also be simplified. If the drawing is 2D and still appears empty, send us the file — it helps us improve.

Why does the measurement not match my artwork?

Measurement accuracy depends on the units recorded inside the file:

  • DXF — the drawing's own units setting is used. If the file was saved without units, ViewVector assumes millimetres.
  • PDF / AI — page points are used, which is exact for print-sized documents.
  • SVG — physical size comes from the file's width / height. An SVG saved without units is treated as CSS pixels (96 per inch), which is the web standard.

Switch between millimetres and inches in Settings; every measurement updates immediately.

What does Bleed Preview show?

A 3 mm bleed zone, highlighted as a band around the edge of the artwork, plus a dashed line marking where the trim would fall. It answers one question quickly: will this artwork trim safely? It does not change the file, and nothing is exported with the highlight.

Where do exported files go?

Exports are created on your device, then handed to the standard iOS share sheet. From there you can save to Files, send by Mail or Messages, or pass the proof to another app. PNG exports are high-resolution bitmaps; PDF exports keep the original page size and remain vector where the source allowed it.

Files over 100 MB

Very large files cannot be previewed on a phone without risking a crash, so ViewVector limits opening files above roughly 100 MB and asks for confirmation above 30 MB. Splitting a large multi-page PDF into single pages usually solves it.

Does ViewVector need an internet connection?

No. ViewVector works entirely offline and has no network access at all. That is deliberate: your clients' artwork never leaves your device. See the privacy page for details.

Managing recent files

The home screen lists recently opened files with thumbnails. Touch and hold an entry to remove it, or use Clear Recents in Settings to remove every entry and its local copy at once. Removing a history entry never touches the original file in Files, iCloud, Dropbox or wherever it came from.
