Questions, answered

Does LogLens++ send my logs anywhere?

No. LogLens++ contains no networking code — no analytics, no crash reporting, no cloud. Logs are parsed and stored exclusively inside your device's sandbox, and deleting a file removes it permanently.

How big can my logs be?

Files are streamed and indexed rather than loaded whole, with a virtualized reader built for very large files. Gzip archives up to 256 MB decompressed are supported.

Which log formats are recognized?

log4j-style timestamps, JSON lines, syslog, and plain text are auto-detected; severity levels (ERROR/WARN/INFO/DEBUG) are classified with editable rules you can tune in Settings.

Is it a subscription?

Never. LogLens++ is a single one-time purchase that unlocks everything, forever.
