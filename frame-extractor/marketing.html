Common questions

Is FrameGrab a subscription?

No. It is a one-time purchase. No subscription, no recurring charge, no in-app purchases and no ads.

Do my videos leave my device?

Never. Decoding, extraction and saving all run on your device using Apple's frameworks. There is no upload, no account and no server-side storage.

Are the exported images really full quality?

Yes. Frames are decoded at the source video's resolution — not a screenshot of the screen. You can also deliberately scale the output to 1080p or 720p when a smaller file is more useful.

How many frames can I extract at once?

Up to 100 frames per run, which keeps each batch predictable in time, memory and storage. Need more? Run the next section of the video as a second batch — everything lands in the same gallery.

Does it work offline?

Completely. FrameGrab needs no network access at all.

Does it edit or convert video?

No. FrameGrab exports still images only — it does not trim, record, re-encode or convert video.
