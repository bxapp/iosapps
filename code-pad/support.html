Quick answers

How do I open a file?

Two ways:

  • Tap Open File in the app and pick a document from the Files app (including iCloud Drive).
  • In another app (Mail, Slack, WeChat, …), tap Share → Open in CodePad++, or use the share sheet's Open In action on a file in the Files app.

Recently opened files appear on the home screen for one-tap access. Long-press an entry to remove it, or use Settings → Clear entries to remove all of them.

Which formats are supported?

Any text-based file. Built-in syntax highlighting covers 31 languages, including: log, txt, json, yaml / yml, ini / conf / cfg, toml, xml, html, css, js / jsx, ts / tsx, java, go, c / cpp, csharp, swift, kotlin, rust, php, dart, python, ruby, lua, shell, dockerfile, sql, markdown, diff, graphql, http and properties.

Files with unknown extensions are sniffed automatically — if they're text they open fine.

Can I open .gz compressed logs?

Yes. Gzipped logs (.log.gz, .txt.gz, …) are decompressed in the background with a progress indicator, then cached locally — the next open is instant. No manual extraction needed.

How large a file can it handle?

There is no hard limit. CodePad++ reads files in chunks and renders a virtualized list, so only the visible portion stays in memory — 100MB+ logs scroll smoothly and search stays responsive.

How do I search, copy or jump to a line?

Use the toolbar at the bottom of the viewer:

  • Search — global search with match highlighting, next/previous jump and case sensitivity.
  • Copy — copy the current line, select multiple lines, or copy the whole file (up to 5MB).
  • # — jump to any line number; ↑ ↓ — jump to top or bottom.
  • Aa — font size, code theme, wrapping and line numbers.
Does CodePad++ collect my data?

No. CodePad++ is fully offline: it makes no network requests, contains no analytics or tracking, and has no accounts. Files are processed entirely on your device. See the Privacy Policy for details.
