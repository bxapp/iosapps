FAQ

Short answers, no fine print.

Does CodePad++ upload my files?

No. CodePad++ makes zero network requests — there is no server, no account and no analytics. Files are processed entirely on your device.

Is it a subscription?

No. CodePad++ is a one-time purchase. Every feature is unlocked from day one, and all future updates are included.

How large a file can it open?

There is no hard limit. 100MB+ logs scroll smoothly thanks to chunked reading and a virtualized list; only the visible portion stays in memory.

Can it open .gz logs?

Yes. Gzipped logs are decompressed in the background and cached locally, so they open instantly next time.

Which languages is it available in?

English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français, Deutsch, Português, Русский and Italiano.
